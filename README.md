# Kishharmony Child Theme

این قالب بچهٔ ساده برای TwentyTwentyOne شامل ساختار اولیه است تا بتوانید قابلیت‌ها را تست کنید.

نحوه دانلود و نصب:
1. از گیت‌هاب شاخهٔ add/kishharmony-child-theme را دانلود به صورت ZIP: https://github.com/amiralifashtanghi-sketch/Kishharmony.ir/archive/refs/heads/add/kishharmony-child-theme.zip
2. فایل ZIP را باز کنید و پوشه `kishharmony-child-theme` را به صورت ZIP مجزا بسازید یا از آن در پوشه themes استفاده کنید.
3. در وردپرس به بخش پوسته‌ها → افزودن → بارگذاری پوسته بروید و ZIP را نصب و فعال کنید.

توجه: این بسته شامل نمونه داده نیست اما چند پست CPT و تنظیمات متا را دارد که می‌توانید در بخش ادمین اضافه کنید.
