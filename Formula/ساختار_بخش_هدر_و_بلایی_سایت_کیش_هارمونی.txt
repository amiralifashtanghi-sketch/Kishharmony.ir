## پروژه: هدر شیشه‌ای، لوگوی شناور و باکس دسته‌بندی خدمات

## 🧱 ۰. ساختار کلی فایل و پیش‌نیازها

فایل از نوع **HTML5** و با جهت‌گیری **راست‌به‌چپ (RTL)** برای زبان فارسی طراحی شده است (`dir="rtl"`).  
تمامی استایل‌ها داخل تگ `<style>` و تمام اسکریپت‌ها داخل تگ `<script>` در همان فایل نوشته شده‌اند (هیچ فایل خارجی وجود ندارد).

- **زبان:** `lang="fa"`
- **Viewport:** `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- **فونت:** از فونت سیستمی استفاده شده است:  
  `font-family: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;`

## 📌 ۱. استایل‌های ریست (Reset) و پایه

```css
*,
*::before,
*::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

body {
    font-family: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;
    background-color: #ffffff;
    color: #1e293b;
    line-height: 1.5;
    min-height: 200vh; /* برای ایجاد قابلیت اسکرول */
}
```

- **`box-sizing: border-box`** روی تمام المان‌ها اعمال می‌شود تا محاسبات پدینگ و حاشیه ساده‌تر باشد.
- **`min-height: 200vh`** در body تضمین می‌کند که صفحه به‌اندازه کافی بلند باشد تا کاربر بتواند اسکرول کند و تمام افکت‌ها را ببیند.

## 🧭 ۲. هدر (Header)

### ۲.۱. کانتینر اصلی هدر (کلاس `header`)

**نمای کلی (همیشه ثابت):**
```css
.header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 70px;
    z-index: 1000;
    display: flex;
    align-items: center;
    justify-content: space-between;
    padding: 0 1.8rem;
    background: transparent;
    border: 1px solid transparent;
    border-radius: 0;
    box-shadow: none;
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
    transition: all 0.8s cubic-bezier(0.45, 0, 0.55, 1.0);
}
```

**توضیح جزء‌به‌جزء:**
- **`position: fixed`** باعث می‌شود هدر همواره بالای صفحه بچسبد.
- **`top: 0; left: 0; width: 100%`** – کل عرض صفحه را می‌پوشاند.
- **`height: 70px`** – ارتفاع ثابت اولیه.
- **`z-index: 1000`** – بالاتر از محتوای عادی (اما پایین‌تر از لوگو که z-index: 2000 دارد).
- **`display: flex`** و تنظیمات تراز: آیتم‌های داخلی در یک ردیف قرار می‌گیرند و فضای بین آن‌ها با `space-between` توزیع می‌شود.
- **`padding: 0 1.8rem`** – فاصله داخلی از چپ و راست.
- **`background: transparent`** – در حالت عادی کاملاً شفاف.
- **`border: 1px solid transparent`** – یک حاشیه نامرئی برای جلوگیری از جهش ناگهانی هنگام اضافه شدن حاشیه در حالت شیشه‌ای.
- **`border-radius: 0`** – بدون گردی.
- **`box-shadow: none`** – بدون سایه.
- **`backdrop-filter: none`** – بدون تاری پشت زمینه.
- **`transition: all 0.8s cubic-bezier(0.45, 0, 0.55, 1.0)`** – تمام تغییرات (رنگ، سایه، اندازه، گردی و ...) با یک انیمیشن ۰.۸ ثانیه‌ای و منحنی شتاب ملایم انجام می‌شود.

### ۲.۲. هدر در حالت اسکرول شده (کلاس `scrolled`)

وقتی کاربر بیش از ۱۰px اسکرول کند، توسط جاوااسکریپت کلاس `scrolled` به هدر اضافه می‌شود.

```css
.header.scrolled {
    background: rgba(255, 255, 255, 0.18);
    backdrop-filter: blur(28px) saturate(200%);
    -webkit-backdrop-filter: blur(28px) saturate(200%);
    border-radius: 50px;
    top: 14px;
    left: 3%;
    width: 94%;
    height: 58px;
    padding: 0 2.2rem;
    border: 1px solid rgba(255, 255, 255, 0.35);
    box-shadow:
        0 20px 40px -12px rgba(0, 0, 0, 0.15),
        0 4px 12px rgba(0, 0, 0, 0.08),
        inset 0 1px 0 rgba(255, 255, 255, 0.5);
}
```

- **`background: rgba(255, 255, 255, 0.18)`** – سفید با شفافیت ۱۸٪ (حالت شیشه‌ای).
- **`backdrop-filter: blur(28px) saturate(200%)`** – تاری ۲۸ پیکسلی و افزایش اشباع رنگ پشت هدر. نسخه `-webkit-` برای سافاری نیز تکرار شده.
- **`border-radius: 50px`** – گوشه‌های کاملاً گرد (کپسولی).
- **`top: 14px`** – از بالای صفحه ۱۴px فاصله می‌گیرد (شناور می‌شود).
- **`left: 3%; width: 94%`** – از طرفین جمعاً ۶٪ فاصله (۳٪ از هر طرف).
- **`height: 58px`** – کمی فشرده‌تر از حالت عادی.
- **`padding: 0 2.2rem`** – فاصله داخلی بیشتر.
- **`border: 1px solid rgba(255, 255, 255, 0.35)`** – حاشیه سفید نیمه شفاف.
- **`box-shadow`** از سه لایه تشکیل شده:
  1. سایه بیرونی بزرگ و نرم: `0 20px 40px -12px rgba(0,0,0,0.15)`
  2. سایه بیرونی کوچک‌تر: `0 4px 12px rgba(0,0,0,0.08)`
  3. سایه داخلی روشن در لبه بالایی: `inset 0 1px 0 rgba(255,255,255,0.5)`

### ۲.۳. چینش داخلی هدر (سه ناحیه)

ساختار HTML:
```html
<header class="header" id="header">
    <div class="header__left"> ... </div>
    <div class="header__center"> <!-- خالی --> </div>
    <div class="header__right"> ... </div>
</header>
```

استایل:
```css
.header__left {
    flex: 1;
    display: flex;
    justify-content: flex-start;
}
.header__center {
    flex: 1;
}
.header__right {
    flex: 1;
    display: flex;
    justify-content: flex-end;
    gap: 1rem;
}
```

- هر سه ناحیه `flex: 1` دارند تا فضای مساوی بگیرند.
- `header__left` محتویات خود را به چپ می‌چسباند (در RTL یعنی ابتدای هدر).
- `header__center` خالی است و صرفاً برای تعادل فضای بین چپ و راست ایجاد شده.
- `header__right` محتویات را به راست می‌چسباند (انتهای هدر) و بین آیکون‌ها `gap: 1rem` فاصله می‌گذارد.

### ۲.۴. دکمه همبرگر (Hamburger Menu)

HTML:
```html
<button class="hamburger" aria-label="منو">
    <span></span>
    <span></span>
    <span></span>
</button>
```

CSS:
```css
.hamburger {
    display: flex;
    flex-direction: column;
    justify-content: space-between;
    width: 36px;
    height: 28px;
    padding: 0.5rem;
    background: none;
    border: none;
    cursor: pointer;
    gap: 5px;
}
.hamburger span {
    display: block;
    height: 2.5px;
    background-color: #2d2d2d;
    border-radius: 3px;
}
```

- **ابعاد کلی دکمه:** ۳۶×۲۸px به‌اضافه padding 0.5rem.
- **چیدمان سه خط:** با `flex-direction: column; justify-content: space-between; gap: 5px`، خطوط به‌صورت مساوی از هم فاصله می‌گیرند.
- **ظاهر خطوط:** ضخامت `2.5px`، رنگ `#2d2d2d`، گوشه‌های گرد `3px`.
- هیچ افکت هاوری برای خود دکمه تعریف نشده است.

### ۲.۵. آیکون‌های سمت راست (سبد خرید و حساب کاربری)

HTML:
```html

</a>
<a href="#" class="header__icon" aria-label="حساب کاربری">
```

CSS:
```css
.header__icon {
    display: flex;
    align-items: center;
    justify-content: center;
    width: 38px;
    height: 38px;
    border-radius: 12px;
    background: transparent;
```

- **ابعاد هر آیکون:** ۳۸×۳۸px.
- **گردی:** ۱۲px.

## 🎨 ۳. کانتینر آبی (Hero) و پس‌زمینه

```css
.hero {
    width: 100%;
    background-color: #1a56db;
    padding-top: 70px;  /* جبران ارتفاع هدر ثابت */
    position: relative;
    height: 542px;      /* مقدار دقیق برای دسکتاپ */
    overflow: visible;
}
```

- **رنگ پس‌زمینه:** آبی `#1a56db` یکدست.
- **`padding-top: 70px`** باعث می‌شود محتوای داخل hero (بنر و باکس) زیر هدر شفاف نرود.
- **`height: 542px`** – این ارتفاع به‌صورت دستی محاسبه شده تا دقیقاً شامل هدر (70px) + بنر (360px) + دو ردیف اول دسته‌بندی (حدود 112px) باشد. (70+360+112 = 542)
- **`overflow: visible`** اجازه می‌دهد باکس دسته‌بندی از لبه پایینی hero بیرون بزند و روی پس‌زمینه سفید بعدی قرار گیرد.
- **`position: relative`** برای محتوای داخلی نیاز است.

> توجه: در واکنش‌گرایی، ارتفاع hero به‌تناسب تغییر می‌کند (در ادامه توضیح داده می‌شود).

## 🎯 ۵. لوگوی شناور (Floating Logo)

این بخش پیچیده‌ترین و حیاتی‌ترین بخش پروژه است. لوگو از نظر بصری در مرکز بنر شروع می‌شود و با اسکرول کاربر به مرکز هدر (در حالت شیشه‌ای) حرکت می‌کند.

### ۵.۱. ساختار HTML

```html
<a href="#" class="floating-logo" id="floatingLogo">
    <span class="logo-icon">✦</span>
    <span class="logo-text">برند شما</span>
</a>
```

### ۵.۲. استایل پایه (CSS)

```css
.floating-logo {
    position: fixed;
    z-index: 2000;
    display: flex;
    align-items: center;
    gap: 0.6rem;
    color: white;
    text-decoration: none;
    white-space: nowrap;
    left: 50%;
    top: 0; /* با JS مقداردهی می‌شود */
    transform: translate(-50%, -50%);
    will-change: top;
}
```

- **`position: fixed`** – لوگو از جریان صفحه خارج و نسبت به viewport ثابت می‌شود.
- **`z-index: 2000`** – بالاتر از هدر (که ۱۰۰۰ است) تا روی هدر هم دیده شود.
- **`left: 50%`** – مرکز افقی صفحه.
- **`transform: translate(-50%, -50%)`** – مرکز دقیق لوگو را در نقطه‌ای که `top` مشخص می‌کند قرار می‌دهد (هم افقی هم عمودی).
- **`top`** در ابتدا توسط جاوااسکریپت روی مرکز بنر تنظیم می‌شود.
- **`will-change: top`** – به مرورگر اطلاع می‌دهد که ویژگی `top` تغییر خواهد کرد و بهینه‌سازی GPU را فعال می‌کند.

#### ۵.۲.۱. آیکون لوگو (`.logo-icon`)

```css
.logo-icon {
    display: flex;
    align-items: center;
    justify-content: center;
    background: rgba(255, 255, 255, 0.2);
    backdrop-filter: blur(4px);
    -webkit-backdrop-filter: blur(4px);
    border-radius: 18px;
    font-size: 1.8rem;
    width: 56px;
    height: 56px;
}
```

- **اندازه اولیه:** ۵۶×۵۶px.
- **گردی:** ۱۸px.
- **پس‌زمینه:** سفید نیمه‌شفاف با blur.
- **متن داخل:** «✦» با اندازه فونت `1.8rem` و وسط‌چین شده.
- **تغییر اندازه و گردی** در JS انجام می‌شود.

#### ۵.۲.۲. متن برند (`.logo-text`)

```css
.logo-text {
    font-weight: 800;
    text-shadow: 0 2px 8px rgba(0, 0, 0, 0.2);
    font-size: 2.2rem;
}
```

- **فونت اولیه:** `2.2rem` وزن ۸۰۰.
- **سایه متن:** برای خوانایی روی پس‌زمینه آبی.

### ۵.۳. رفتار پویا با JavaScript

تمام انیمیشن‌ها با `requestAnimationFrame` کنترل می‌شود. منطق اصلی در تابع `onScroll` و `updateLogo` قرار دارد.

#### ۵.۳.۱. محاسبه موقعیت‌های مرجع

دو متغیر اصلی:
- **`bannerCenterY`**: فاصله مرکز بنر از بالای viewport (پویا، با تغییر اندازه پنجره به‌روزرسانی می‌شود).
- **`headerCenterY`**: فاصله مرکز هدر در حالت شیشه‌ای از بالای viewport (بر اساس breakpoint محاسبه می‌شود).

```javascript
function updatePositions() {
    const bannerRect = banner.getBoundingClientRect();
    bannerCenterY = bannerRect.top + bannerRect.height / 2;

    const width = window.innerWidth;
    let scrolledTop, scrolledHeight;
    if (width <= 480) {
        scrolledTop = 6;       // top هدر در موبایل
        scrolledHeight = 52;
    } else if (width <= 768) {
        scrolledTop = 8;       // top هدر در تبلت
        scrolledHeight = 52;
    } else {
        scrolledTop = 14;      // top هدر در دسکتاپ
        scrolledHeight = 58;
    }
    headerCenterY = scrolledTop + scrolledHeight / 2;

    if (window.scrollY <= 10) {
        floatingLogo.style.top = bannerCenterY + 'px';
    }
}
```

#### ۵.۳.۲. تابع easing (نرم‌سازی حرکت)

برای ایجاد حس نرم‌تر در شروع و پایان حرکت، از یک تابع درجه سه استفاده شده است:

```javascript
function easeInOutCubic(t) {
    return t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2;
}
```

#### ۵.۳.۳. محاسبه progress و به‌روزرسانی

```javascript
function getScrollProgress() {
    const maxScroll = 200; // محدوده اسکرول (200px)
    const raw = Math.min(window.scrollY / maxScroll, 1.0);
    return easeInOutCubic(raw);
}

function updateLogo(progress) {
    const currentY = bannerCenterY + (headerCenterY - bannerCenterY) * progress;
    floatingLogo.style.top = currentY + 'px';

    const iconSize = LARGE_ICON_SIZE + (SMALL_ICON_SIZE - LARGE_ICON_SIZE) * progress;
    const textSizeRem = LARGE_TEXT_SIZE_REM + (SMALL_TEXT_SIZE_REM - LARGE_TEXT_SIZE_REM) * progress;

    logoIcon.style.width = iconSize + 'px';
    logoIcon.style.height = iconSize + 'px';
    logoIcon.style.fontSize = (iconSize * 0.55) + 'px';
    logoText.style.fontSize = textSizeRem + 'rem';

    floatingLogo.style.color = progress > 0.8 ? '#1e1e2f' : 'white';

    const borderRadius = 18 + (12 - 18) * progress;
    logoIcon.style.borderRadius = borderRadius + 'px';
}
```

- **`maxScroll = 200`** – بعد از ۲۰۰px اسکرول، progress به ۱ می‌رسد.
- **`progress`** بین ۰ تا ۱، با اعمال easing.
- **`currentY`** موقعیت عمودی مرکز لوگو را تعیین می‌کند.
- **تغییر اندازه آیکون:** از ۵۶px به ۳۶px (متغیرهای `LARGE_ICON_SIZE` و `SMALL_ICON_SIZE`).
- **تغییر اندازه متن:** از `2.2rem` به `1.3rem` (`LARGE_TEXT_SIZE_REM`, `SMALL_TEXT_SIZE_REM`).
- **اندازه فونت داخل آیکون** متناسب با اندازه آیکون (`iconSize * 0.55`) محاسبه می‌شود تا «✦» همیشه وسط بماند.
- **تغییر رنگ:** در ۸۰٪ انتهایی حرکت، رنگ متن از سفید به `#1e1e2f` تغییر می‌کند.
- **تغییر گردی آیکون:** از `18px` به `12px`.

#### ۵.۳.۴. حلقه انیمیشن با requestAnimationFrame

```javascript
let ticking = false;

function onScroll() {
    if (window.scrollY > 10) {
        header.classList.add('scrolled');
    } else {
        header.classList.remove('scrolled');
    }

    if (!ticking) {
        requestAnimationFrame(() => {
            const progress = getScrollProgress();
            updateLogo(progress);
            ticking = false;
        });
        ticking = true;
    }
}

window.addEventListener('scroll', onScroll, { passive: true });
```

- با هر رویداد scroll، اگر `ticking` فعال نباشد، یک `requestAnimationFrame` صف می‌شود.
- درون callback، progress گرفته شده و لوگو به‌روز می‌شود.
- `{ passive: true }` برای بهبود performance اسکرول.

#### ۵.۳.۵. مدیریت resize

```javascript
window.addEventListener('resize', () => {
    updatePositions();
    const progress = getScrollProgress();
    updateLogo(progress);
});
```

با تغییر اندازه پنجره، موقعیت‌های مرجع دوباره محاسبه شده و لوگو بلافاصله در جای صحیح قرار می‌گیرد.

## 📱 ۷. واکنش‌گرایی (Responsive)

### ۷.۱. تبلت (عرض حداکثر ۷۶۸px)

```css
@media screen and (max-width: 768px) {
    .header {
        height: 62px;
        padding: 0 1rem;
    }
    .header.scrolled {
        border-radius: 35px;
        top: 8px;
        left: 2%;
        width: 96%;
        height: 52px;
        padding: 0 1.5rem;
    }
    .banner {
        height: 260px;
    }
    .logo-icon {
        width: 46px;
        height: 46px;
        font-size: 1.4rem;
    }
    .logo-text {
        font-size: 1.6rem;
    }
    .categories-wrapper {
        margin: 0 32px;
    }
    .categories-grid {
        border-radius: 20px;
    }
    .category-item {
        padding: 0.6rem 0.8rem;
    }
    .category-emoji {
        font-size: 1.1rem;
    }
    .category-text {
        font-size: 0.8rem;
    }
    .hero {
        height: calc(62px + 260px + 112px); /* = 434px */
        padding-top: 62px;

```

- ارتفاع هدر کاهش یافته، فاصله داخلی کم شده.
- حالت شیشه‌ای هدر: گردی ۳۵px، فاصله از بالا ۸px، عرض ۹۶٪.
- بنر: ۲۶۰px.
- سایز اولیه لوگو: آیکون ۴۶px، متن `1.6rem` (در JS برای حالت کوچک همیشه ۳۶px و ۱.۳rem استفاده می‌شود، صرف‌نظر از breakpoint).
- مارجین باکس: ۳۲px.
- پدینگ و سایز فونت آیتم‌ها کاهش.
- ارتفاع hero با calc به‌روز شده.

## 🧪 ۱۰. نکات فنی بسیار مهم برای بازتولید دقیق

1. **RTL اجباری است.** حاشیه‌های `border-right` در آیتم‌های دسته‌بندی و `margin-right: auto` برای نشان، با توجه به جهت صفحه تعریف شده‌اند. در صورت LTR شدن، باید جای right و left تعویض شود.
2. **ترتیب CSS مهم است.** `overflow: hidden` روی شبکه دسته‌بندی، گوشه‌های گرد را اعمال می‌کند و حاشیه‌های داخلی آیتم‌ها را در بر می‌گیرد.
3. **ارتفاع hero دقیقاً جمع ارتفاع بنر + ۱۱۲px + ارتفاع هدر اولیه است.** اگر ارتفاع بنر یا هدر تغییر کند، باید hero هم به‌روز شود (در responsive با calc این کار خودکار شده).
4. **لوگو هیچ `transition` در CSS ندارد.** تمام حرکات frame به frame توسط JS کنترل می‌شود تا با easing سفارشی هماهنگ باشد. اگر CSS transition روی `top` یا `transform` لوگو بگذارید، انیمیشن دوگانه و ناهماهنگ می‌شود.
5. **`will-change: top`** روی لوگو برای افزایش performance استفاده شده است.
6. **رویداد resize** حتماً `updatePositions` را صدا می‌زند تا در صورت چرخش دستگاه یا تغییر اندازه پنجره، موقعیت‌ها بازمحاسبه شوند.
7. **`passive: true`** در listener اسکرول برای جلوگیری از تأخیر در scroll performance استفاده شده است.
8. **SVG آیکون‌ها:** مسیرها دقیقاً کپی شوند. `stroke-width: 1.8` و `stroke-linecap: round` ضروری هستند.
9. **کلاس `special`** فقط رنگ متن را عوض می‌کند، نه استایل‌های دیگر.
10. **نشان (badge)** فقط در آیتم «ویژه» وجود دارد.
