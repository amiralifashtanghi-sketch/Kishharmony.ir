## ۷. سیستم اسکرول و Snap

### ۷.۱. اسکرول اسنپ (Scroll Snap)

```css
.scroll-container {
    scroll-snap-type: x mandatory;
}
.card-group {
    scroll-snap-align: start;
    width: 100%;
}
```

این تنظیمات باعث می‌شوند هر گروه از سه کارت، دقیقاً در مرکز (یا ابتدای) viewport قرار گیرد و کاربر نتواند بین دو گروه متوقف شود.

### ۷.۲. دکمه‌های اسکرول

```html
<button onclick="document.getElementById('scroller').scrollBy({left:-1000,behavior:'smooth'})">
```

مقدار ۱۰۰۰ پیکسل تقریباً به اندازه عرض یک گروه کامل است. `behavior:'smooth'` اسکرول نرم را تضمین می‌کند.

### ۷.۳. کشیدن با موس (Drag to Scroll)

```javascript
const scroller = document.getElementById('scroller');
let isDown = false, startX, scrollLeftPos;

scroller.addEventListener('mousedown', (e) => {
    isDown = true;
    scroller.style.cursor = 'grabbing';
    startX = e.pageX - scroller.offsetLeft;
    scrollLeftPos = scroller.scrollLeft;
});

scroller.addEventListener('mouseleave', () => {
    isDown = false;
    scroller.style.cursor = 'grab';
});

scroller.addEventListener('mouseup', () => {
    isDown = false;
    scroller.style.cursor = 'grab';
});

scroller.addEventListener('mousemove', (e) => {
    if (!isDown) return;
    e.preventDefault();
    const x = e.pageX - scroller.offsetLeft;
    const walk = (x - startX) * 1.5; // ضریب ۱.۵ برای سرعت بیشتر
    scroller.scrollLeft = scrollLeftPos - walk;
});
```

**نکته:** کرسر در حالت عادی `grab` و در حالت کشیدن `grabbing` است. ضریب ۱.۵ باعث می‌شود حرکت موس نسبت به اسکرول واقعی ۱.۵ برابر سریع‌تر باشد که تجربه کاربری روان‌تری ایجاد می‌کند.

## ۹. سایه‌ها (Box Shadows)

سه سطح سایه تعریف شده که همگی از رنگ آبی برند با opacity کم استفاده می‌کنند:

```css
--shadow-sm:  0 2px 8px  rgba(11, 99, 216, 0.06);
--shadow-md:  0 6px 22px rgba(11, 99, 216, 0.10);
--shadow-lg:  0 14px 38px rgba(11, 99, 216, 0.16);
```

**کاربردها:**
- `shadow-sm`: حالت پیش‌فرض کارت‌ها
- `shadow-lg`: حالت hover کارت‌ها
- `shadow-md`: استفاده نشده در این نسخه اما برای توسعه‌های بعدی در دسترس است.

**سایه دکمه‌های اسکرول:**
```css
box-shadow: 0 4px 12px rgba(11,99,216,0.12);
```

**سایه دکمه رزرو:**
```css
box-shadow: 0 4px 14px rgba(255,138,0,0.25);  /* پیش‌فرض */
box-shadow: 0 8px 24px rgba(255,138,0,0.45);  /* hover */
```

**سایه تصویر خودرو:**
```css
box-shadow: 0 6px 18px rgba(11, 99, 216, 0.2);   /* پیش‌فرض */
box-shadow: 0 10px 28px rgba(11, 99, 216, 0.35); /* hover */
```

## ۱۱. نکات ریز و فوت‌های کوزه‌گری

۱. **ترتیب آیکون‌های Font Awesome:** همیشه از استایل `fas` (Solid) استفاده شده است.

۲. **فاصله‌ها (Gap):** تمام gapها با اعداد زوج (4px, 8px, 14px, 16px) تنظیم شده‌اند تا ریتم بصری منظمی ایجاد شود.

۳. **گردی گوشه‌ها (Border Radius):** تصاویر ۱۶px، کارت‌ها ۲۰px، دکمه‌ها ۱۸px، تگ‌ها ۸px، نشان ویژه ۱۰px. این تنوع باعث ایجاد سلسله‌مراتب بصری می‌شود.

۴. **`:root` و متغیرها:** تمام رنگ‌ها و مقادیر تکراری در `:root` تعریف شده‌اند تا تغییرات بعدی آسان باشد.

۵. **عدم استفاده از `!important`:** در هیچ جای کد از `!important` استفاده نشده تا specificity قابل پیش‌بینی باقی بماند.

۶. **`white-space: nowrap`:** روی دکمه‌ها، تگ‌ها، قیمت‌ها و متن راهنما اعمال شده تا از شکستن خط جلوگیری شود.

۷. **`flex-shrink: 0`:** روی تصاویر، دکمه‌های اسکرول و بخش car-action اعمال شده تا این المان‌ها هرگز کوچک نشوند.

۸. **رنگ `#fafeff` در hover کارت:** این رنگ بسیار نزدیک به سفید اما با ته‌رنگ آبی است که حس طراوت و دریا را تداعی می‌کند.

۹. **خط زیر لوگو:** با `opacity: 0.4` و `z-index: -1` طوری طراحی شده که هرگز خوانایی متن را مختل نکند.

۱۰. **اتصال CDN فونت وزیرمتن:** از نسخه `v33.003` استفاده شده که شامل تمام وزن‌هاست و با `font-face` آماده می‌شود.

## ۱۲. خلاصه چک‌لیست بازسازی

اگر بخواهید این طراحی را از صفر بازسازی کنید:

6. مطمئن شوید که `id="scroller"` دقیقاً روی `<div class="scroll-container">` تنظیم شده باشد.
7. بررسی کنید که تمام کلاس‌های `grad1` تا `grad5` به تصاویر اختصاص داده شده باشند.
8. در موبایل تست کنید که چیدمان عمودی و مخفی شدن متن راهنما کار کند.
